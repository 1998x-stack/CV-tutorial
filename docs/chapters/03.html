CHAPTER 03 · HANDCRAFTED FEATURES

传统视觉特征：SIFT、HOG 与 Haar

在端到端深度学习普及前，工程师如何把不稳定的像素变成更可匹配、更可分类的局部描述？

为什么单纯比较像素很脆弱？

同一栋楼在不同光照、缩放、旋转和相机位置下，像素位置与数值都会改变。直接用两幅照片逐像素相减，无法可靠回答“是不是同一个地方”。传统特征方法的想法是先提取更稳定的局部结构：角点、边缘方向、纹理统计，再用这些结构建立匹配或训练分类器。

稳定不等于不变：SIFT 能对尺度和图像内旋转做规范化，HOG 对局部光照有一定鲁棒性，但严重透视变形、遮挡和纹理重复仍会带来失败。选择描述子之前要明确预计会发生哪些变化。

SIFT：先在尺度空间找结构，再描述局部方向

SIFT（Scale-Invariant Feature Transform）构造不同尺度的高斯平滑图像，计算相邻尺度的高斯差分（DoG）；在空间加尺度的三维邻域中寻找局部极值，再做位置精炼和不稳定响应筛除。随后为关键点分配主方向，并在对齐方向的局部邻域统计梯度方向信息。

标准 SIFT 描述子常由 4×4 个局部子区块，每区块 8 个方向桶组成：最终 128 维。梯度幅值用于加权投票，描述子会归一化并对较大分量截断后再次归一化，以降低局部对比度变化的影响。方向分配与归一化用于减轻旋转和亮度变化影响，但这不保证对任意视角、模糊和遮挡都不变。

4×4×8=128

维度来自空间网格与方向分箱；OpenCV SIFT 默认输出 128 个分量。

D(x,y,σ)=L(x,y,kσ)−L(x,y,σ)

L 是高斯模糊后的图像；同一 octave 中 k 为相邻尺度倍数，DoG 是两尺度差值。

HOG：把局部轮廓归纳为方向直方图

HOG（Histogram of Oriented Gradients）估计像素梯度，将其幅值按方向分配到相应直方图桶。局部 cell 的描述能记录边缘大致朝向；多个 cell 组成 block 后归一化，有助于削弱整体对比度变化。用重叠 block 的统计向量串接，得到适用于传统分类器的特征。

原始 Dalal–Triggs 工作用于行人检测，涉及细致的梯度计算、方向分箱、block 归一化与窗口分类。常见 unsigned orientation 将方向范围设为 0–180°；cell 直方图按梯度幅值加权，block 使用 L2-Hys 归一化。不要把“9 个桶”误读成整个 HOG 必定只有 9 维：维度由窗口大小、cell、block 与步长共同决定。

Haar-like 特征与积分图：快速计算矩形差分

Haar-like 特征比较相邻亮暗矩形区域的像素和。在大量候选窗口上反复计算区域和成本很高，积分图将左上角到当前位置的累积和预先存储，使任意轴对齐矩形可以由四个角的积分值组合得到。Viola–Jones 在此基础上结合 AdaBoost 特征选择与级联检测器，让容易判定的负窗口尽早退出。

若积分图 S(x,y) 含原点到 (x,y) 的闭区间像素和，则矩形 [x1,x2]×[y1,y2] 的和为 S(x2,y2) - S(x1-1,y2) - S(x2,y1-1) + S(x1-1,y1-1)；约定越界累积值为零。公式只适用于相应的坐标与闭区间定义。

Sum=S(x2,y2)−S(x1−1,y2)−S(x2,y1−1)+S(x1−1,y1−1)

该式采用包含端点的矩形坐标；如果实现使用带零行/零列的半开区间前缀表，应使用对应索引公式。

SIFT 用于匹配局部关键点；HOG 常用于固定窗口结构分类；Haar 级联面向快速滑窗检测。三者的输入与输出粒度不同，不能仅根据名称比较“谁的精度更高”。

最小可运行实验：方向统计与 SIFT 描述子形状

安装 python -m pip install numpy==2.2.6 opencv-python-headless==4.11.0.86，先用线性灰度梯度构造 9 桶直方图，再在合成几何图上调用 SIFT。合成纹理未必产生稳定关键点，因此只在描述子非空时断言 128 维。

import cv2
import numpy as np

# np.gradient 返回 axis=0 的 gy，再返回 axis=1 的 gx
ramp = np.tile(np.arange(32, dtype=float), (32, 1))
gy, gx = np.gradient(ramp)
assert np.allclose(gx, 1.0) and np.allclose(gy, 0.0)
mag = np.hypot(gx, gy)
angles = (np.degrees(np.arctan2(gy, gx)) + 180) % 180
bins, _ = np.histogram(angles, bins=9, range=(0, 180), weights=mag)
assert bins.shape == (9,) and bins.sum() > 0

# 可重复的角点/纹理网格，保证 SIFT 真正产生描述子
image = np.zeros((192, 192), dtype=np.uint8)
for y in range(24, 168, 24):
    for x in range(24, 168, 24):
        cv2.circle(image, (x, y), 5, 255, -1)
        cv2.rectangle(image, (x + 6, y + 6), (x + 13, y + 13), 180, -1)
sift = cv2.SIFT_create(nfeatures=256)
keypoints, descriptors = sift.detectAndCompute(image, None)
assert descriptors is not None and descriptors.ndim == 2
assert descriptors.shape == (len(keypoints), 128)

# 一个 32×32 窗口：3×3 个 block，每 block 2×2 cells×9 bins
hog = cv2.HOGDescriptor((32, 32), (16, 16), (8, 8), (8, 8), 9)
patch = cv2.resize(image, (32, 32), interpolation=cv2.INTER_AREA)
hog_descriptor = hog.compute(patch)
assert hog_descriptor.size == 324
print("SIFT:", descriptors.shape, "| HOG:", hog_descriptor.shape)

真实特征匹配还需要近邻搜索、距离比值过滤和几何一致性检验；即便描述子看起来接近，也不能直接证明两幅照片属于同一三维场景。

独立验证：积分图四角查询

import numpy as np

image = np.arange(1, 17, dtype=np.int64).reshape(4, 4)
prefix = image.cumsum(axis=0).cumsum(axis=1)

def rectangle_sum(x1, y1, x2, y2):
    # 闭区间坐标；越界前缀值定义为 0
    def at(x, y):
        return 0 if x < 0 or y < 0 else int(prefix[y, x])
    return at(x2, y2) - at(x1-1, y2) - at(x2, y1-1) + at(x1-1, y1-1)

expected = int(image[1:3, 1:4].sum())
assert rectangle_sum(1, 1, 3, 2) == expected
assert expected == 54
print("rectangle sum:", expected)
